JANPASHA MOHAMMAD — AI/ML PORTFOLIO

LOCAL USE
1. Extract this entire ZIP file to a normal folder.
2. Do not run index.html while it is still inside the ZIP preview.
3. Double-click index.html in the extracted folder.

All five artifact landing pages, images, reports, and code links will work locally.

GITHUB PAGES
1. Upload all extracted files and folders to the root of a GitHub repository.
2. Open repository Settings > Pages.
3. Select GitHub Actions under Build and deployment.
4. The included workflow will publish the portfolio.
